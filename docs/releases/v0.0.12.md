# PetPlay v0.0.12

Record PetPlay inside VRChat's camera using a transparent camera layer for OBS. Set it up from
Settings → CAMERA on the wrist menu: calibrate while holding VRChat's camera, then start the
recording layer and capture the “PetPlay VRC Camera” window above VRChat in OBS.

- Live calibration runs in a worker and retains its best fit through pauses, releases and hand
  switches. Sample progress is preserved while collecting a new grip.
- A green ball shows the predicted camera position during calibration and recording. It is
  excluded from the recorded view. Recording resolution is saved between sessions.
- OSC discovery coexists with other applications using port 9001 and advertises the actual
  receiver endpoint to VRChat.
- Recording uses compact scene packets and asynchronous frame pacing, improving observed
  recording-window performance to roughly 58–60 fps in a lighter live scene. Complex scenes
  can still run slower.
- Added synthetic VR camera checks, wrist-menu playtests and SteamVR dashboard controls for
  the VR lab.

The camera integration remains experimental. VRChat camera poses arrive when the camera moves;
move it after enabling OSC if it has not been detected. Judge alignment while holding still.
If OBS's Xcomposite source freezes while the PetPlay window continues updating, disable and
re-enable the PetPlay source to refresh capture.

Desktop builds are produced by release CI for Windows x64 and Linux x64, with an experimental
Linux ARM64 build. Real Steam Frame validation remains incomplete.
